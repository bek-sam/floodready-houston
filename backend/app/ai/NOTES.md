# AI module notes (verified 2026-10-10 against official docs)
- Gemini: `google-genai` -> `genai.Client(api_key=...)`; `client.models.generate_content(model, contents, config=types.GenerateContentConfig(...))`; `client.models.embed_content(model, contents=[...], config=types.EmbedContentConfig(output_dimensionality=768))`.
  Docs list newer stable flash ids (gemini-3.6-flash, gemini-3.8-flash); env default `gemini-2.5-flash` kept (override with GEMINI_MODEL). Embeddings: `gemini-embedding-001` (also `gemini-embedding-2-preview`).
- LangGraph 1.x + `ChatGoogleGenerativeAI(model=..., google_api_key=...)`, `.bind_tools([...])`, tool calls in `AIMessage.tool_calls`, reply with `ToolMessage(tool_call_id=...)`.
- ElevenLabs: REST `POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}?output_format=mp3_44100_128`, header `xi-api-key`, body `{text, model_id}`. Model `eleven_multilingual_v2`; example voice `JBFqnCBsd6RMkjVDRZzb` (override ELEVENLABS_VOICE_ID). SDK: `ElevenLabs(api_key).text_to_speech.convert(...)` yields bytes chunks.
- Backboard: base `https://app.backboard.io/api`, header `X-API-Key`. `POST /assistants {name, system_prompt}` -> `assistant_id`. `POST /threads/messages {content, assistant_id?, thread_id?}` -> `{content, thread_id}`; assistant_id shares memory across threads. Memory-specific endpoints NOT found in docs, so we write the profile as a message to the assistant (best effort) and keep SQLite as source of truth.
- 2026-10-11 efficiency pass: `gemini-2.5-flash`/`2.0-flash` now 404 ("no longer available to new users"), so FALLBACK_MODELS leads with `gemini-3.5-flash` and the fast path remembers 404'd models. Explicit context caching (`client.caches.create`) is supported by the SDK (2.29) and models (`createCachedContent`), but this key is free tier: `TotalCachedContentStorageTokensPerModelFreeTier limit=0`, so cache.ctx_create fails once and turns itself off for an hour (AI_CONTEXT_CACHE=0 disables). Batch chunk embedding also hits 429, so RAG runs BM25-only; single query embeds (semantic answer cache) work when quota allows.
- Env knobs: AI_CACHE, AI_CACHE_DB, AI_TOOL_CACHE, AI_MODEL_ROUTING, AI_CONTEXT_CACHE, AI_TELEMETRY_LOG (all default on / backend/.cache).
